## 1. 建立通信（S1F13 / S1F14）

### Host -> 设备：S1F13（W）

当前实现支持：空体或空列表。

```sml
S1F13 W
  <L [0]>
.
```

### 设备 -> Host：S1F14

```sml
S1F14
  <L [2]
	<B [1] 0>
	<L [2]
	  <A "GWM-PW-20260407">
	  <A "V20260407">
	>
  >
.
```

- `COMMACK=0`：接受
- `COMMACK=1`：拒绝

## 2. 在线状态管理（OffLine / OnLineLocal / OnLineRemote）

> 当前项目采用三态在线模型：
> - `OffLine`：仅允许通信类消息（如 S1F1/S1F13/S1F15/S1F17）
> - `OnLineLocal`：在线本地，不开放远程生产控制
> - `OnLineRemote`：在线远程，允许 S2F41/S16F15/S14F9 等生产控制命令

### 2.1 Host -> 设备：S1F17 Request ON-LINE（W）

```sml
S1F17 W
  <L [0]>
.
```

### 2.2 设备 -> Host：S1F18

```sml
S1F18
  <B [1] 0>
.
```

- `ONLACK=0`：接受，设备切换到 OnLineLocal
- `ONLACK=1`：拒绝

### 2.3 本项目 gRPC：RequestOnlineStatus（Local -> Remote）

> 说明：为满足当前项目远程控制权限切换，OnLineLocal 到 OnLineRemote 通过 gRPC `RequestOnlineStatus` 触发。

### 2.4 Host -> 设备：S1F15 Request OFF-LINE（W）

```sml
S1F15 W
  <L [0]>
.
```

### 2.5 设备 -> Host：S1F16

```sml
S1F16
  <B [1] 0>
.
```

- `OFLACK=0`：接受，设备切换到 OffLine
- `OFLACK=1`：拒绝

## 6. 远程命令（S2F41 / S2F42）

### 3.1 Host -> 设备：S2F41 PPSELECT（W）

> 当前项目建议在 PPSELECT 阶段下发运行前准备参数（含 MODE、PORTID、LOTID、SLOTSLIST）。
> 约定：当 `MODE=00`（全自动）时，`PORTID` 和 `SLOTSLIST` 可以为空，由设备端按默认策略处理。

```sml
S2F41 W
  <L [2]
	<A "PPSELECT">
	<L [4]
	  <L [2] <A "MODE"> <A "01"> >
	  <L [2] <A "PORTID"> <A "1"> >
	  <L [2] <A "LOTID"> <A "26P12345"> >
	  <L [2] <A "SLOTSLIST"> <A "1,3,4,5"> >
	>
  >
.
```

### 3.1.1 PPSELECT（MODE=00，全自动）示例

```sml
S2F41 W
  <L [2]
	<A "PPSELECT">
	<L [4]
	  <L [2] <A "MODE"> <A "00"> >
	  <L [2] <A "PORTID"> <A ""> >
	  <L [2] <A "LOTID"> <A "26P12345"> >
	  <L [2] <A "SLOTSLIST"> <A ""> >
	>
  >
.
```

### 3.1.2 半自动多盒（示例：仅测 2 盒）建议写法

> 标准联调实践中，通常按“每个 Port/每个 Lot 一条 PPSELECT”下发，避免同一条命令混合多个 port 的 lot 语义。
> 例如一次只测 2 盒：`PORTID=1, LOTID=LOT_A` 与 `PORTID=2, LOTID=LOT_B`，分别下发两条 PPSELECT。

```sml
S2F41 W
  <L [2]
	<A "PPSELECT">
	<L [4]
	  <L [2] <A "MODE"> <A "01"> >
	  <L [2] <A "PORTID"> <A "1"> >
	  <L [2] <A "LOTID"> <A "LOT_A"> >
	  <L [2] <A "SLOTSLIST"> <A "1,2,3,4"> >
	>
  >
.

S2F41 W
  <L [2]
	<A "PPSELECT">
	<L [4]
	  <L [2] <A "MODE"> <A "01"> >
	  <L [2] <A "PORTID"> <A "2"> >
	  <L [2] <A "LOTID"> <A "LOT_B"> >
	  <L [2] <A "SLOTSLIST"> <A "1,3,5,7"> >
	>
  >
.
```

### 3.2 设备 -> Host：S2F42

```sml
S2F42
  <L [2]
	<B [1] 0>
	<L [0]>
  >
.
```

- `HCACK=0`：成功

# 完整流程命令交互顺序（建议）

1. Host -> 设备：`S1F13`（建链请求）  
2. 设备 -> Host：`S1F14`  
3. Host -> 设备：`S1F17`（请求在线）  
4. 设备 -> Host：`S1F18`（进入 OnLineLocal）  
5. EFEM/本地调用：`RequestOnlineStatus`（切换到 OnLineRemote）  
6. Host -> 设备：`S2F33`（定义报告）  
7. 设备 -> Host：`S2F34`  
8. Host -> 设备：`S2F35`（绑定 CEID-RPTID）  
9. 设备 -> Host：`S2F36`  
10. Host -> 设备：`S2F37`（启用事件）  
11. 设备 -> Host：`S2F38`  
12. Host -> 设备：`S2F41(PPSELECT)`（下发运行前准备参数，如 MODE/LOTID/SLOTSLIST）  
13. 设备 -> Host：`S2F42`  
14. Host -> 设备：`S3F17`（LOT + SlotMap）  
15. 设备 -> Host：`S3F18`  
16. Host -> 设备：`S16F15`（Create Process Job）  
17. 设备 -> Host：`S16F16`  
18. Host -> 设备：`S14F9`（Create Control Job）  
19. 设备 -> Host：`S14F10`  
20. Host -> 设备：`S2F41(START)`  
21. 设备 -> Host：`S2F42`  
22. 设备 -> Host：`S6F11`（Mapping 结果）  
23. Host -> 设备：`S6F12`  
24. 设备 -> Host：`S6F11`（每片结果，循环 N 次）  
25. Host -> 设备：`S6F12`（每次回）  
26. 设备 -> Host：`S6F11`（整盒完成）  
27. Host -> 设备：`S6F12`

---

## 备注

- `S6F11` 实际发送受 Host 侧 `S2F33/35/37` 配置门禁控制。
- `S2F41/S16F15/S14F9` 等生产控制命令仅在 `OnLineRemote` 状态开放。
- 如需退回离线可走 `S1F15/S1F16`。
