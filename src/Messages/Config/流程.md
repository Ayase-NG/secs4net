# SECS/GEM 联调流程（当前项目可用主流程）

> 本文档按当前已实现链路重写：
> 1) Host 建链与在线切换；
> 2) Host 下发 S2F33/S2F35/S2F37（仅列当前流程需要的 CEID）;
> 3) 设备上报载具到位（CEID=1002）；
> 4) Host 下发 S2F41 PPSELECT + START；
> 5) 设备持续上报结果类 S6F11。

## 6. 完整交互顺序（本主流程）

1. Host `S1F13` -> 设备 `S1F14`
2. Host `S1F17` -> 设备 `S1F18`
3. gRPC `RequestOnlineStatus`（切 `OnLineRemote`）
4. Host `S2F33` -> 设备 `S2F34`
5. Host `S2F35` -> 设备 `S2F36`
6. Host `S2F37` -> 设备 `S2F38`
7. 设备（gRPC 触发）`ReportEvent(CEID=1002)` -> Host `S6F11`
8. Host `S2F41 PPSELECT` -> 设备 `S2F42`
9. Host `S2F41 START` -> 设备 `S2F42`
10. 设备（gRPC 触发）循环 `ReportEvent(CEID=1001)` -> Host 循环 `S6F12`
11. 设备（gRPC 触发）`ReportEvent(CEID=1005)` -> Host `S6F12`

---

## 7. 备注

- 当前上报参数标准键：`CARRIERID`、`SLOTSLIST`、`PORTID`。
- S6F11 最终是否发送、携带哪些 VID，受 Host 下发的 `S2F33/S2F35/S2F37` 运行态控制。
- 若 `S2F35` 返回 `LRACK=5`，表示绑定的 RPTID 未定义，应先检查 `S2F33` 是否成功定义对应 RPTID。
